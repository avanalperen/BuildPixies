# Kullanıcı Testi Protokolü (BP-047)

> **Durum:** Koşulmayı bekliyor — üç gerçek katılımcı gerektirir.
> **Süre:** Katılımcı başına ~10 dakika.
> **Ortam:** `npm run build && npm run start`, tarayıcı gizli sekme.
> **Kural:** Katılımcıya hiçbir ipucu verilmez. Takıldığı yer veri sayılır.

## Katılımcı profili

En az ikisi hedef kitleden olmalı: bootcamp öğrencisi, öğrenci proje takımı
üyesi veya solo founder. Üçüncüsü kapasiteye göre.

## Bölüm 1 — 5 saniye testi

Landing sayfasını **5 saniye** göster, kapat, sonra sor:

1. Bu ürün ne yapıyor?
2. Kime hitap ediyor?

**Başarı ölçütü:** 3 katılımcının en az 2'si ürünü doğru anlatır.

| Katılımcı | Soru 1 cevabı | Soru 2 cevabı | Doğru mu? |
| --- | --- | --- | --- |
| P1 | | | |
| P2 | | | |
| P3 | | | |

## Bölüm 2 — Görev tabanlı test

Katılımcıya sırayla şu görevleri ver, müdahale etme, süreyi ve takılmaları not al.

| # | Görev | Beklenen yol | Süre | Takıldı mı? |
| --- | --- | --- | --- | --- |
| 1 | Ürünün ne ürettiğini kendi gözünle gör | Landing → Sample Blueprint | | |
| 2 | Kendi fikrinle bir proje başlat | Wizard → 4 adım → Summon | | |
| 3 | Blueprint üret ve ilerlemeyi izle | Generate → timeline | | |
| 4 | "Bu projede ilk sprintte ne yapmalıyım?" sorusunu cevapla | Overview → First sprint | | |
| 5 | Kapsamın neyi dışarıda bıraktığını bul | Overview → Out of scope | | |
| 6 | Bir bölümü daraltmak için yönlendir | Product → Refine | | |
| 7 | Teslim için README indir | Delivery Pack → Download | | |

**BP-033 kabul ölçütü:** En az iki katılımcı 4. ve 5. görevi yardım almadan
tamamlamalı.

## Bölüm 3 — Kapanış soruları

1. En kafa karıştırıcı ekran hangisiydi?
2. Eksik olduğunu düşündüğün tek şey ne?
3. Bunu bir arkadaşına önerir miydin? Neden?

## Sonuç kaydı

Doldurulduktan sonra bu dosyanın altına tarih, katılımcı sayısı ve çıkan
aksiyonlar (owner + hedef tarih ile) eklenir. Aksiyonlar Sprint 3
retrospektifine taşınır.
